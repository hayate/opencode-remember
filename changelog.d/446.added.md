- Added: OpenCode host support. A new adapter plugin (`plugin/`) fires the existing hook scripts from OpenCode's event lifecycle (`session.created`, `tool.execute.after`, `message.updated`, `session.deleted`, `dispose`), maintains a Claude-format JSONL mirror of each session that the unchanged pipeline reads, and feeds the SessionStart memory injection into every request. A new `scripts/summarizer-opencode.sh` translates the summarizer's `claude -p` invocation into `opencode run`, selected via the existing `REMEMBER_CLAUDE_BIN` seam. `scripts/save-session.sh`'s session-id gate now accepts the hooks' own id allowlist (Claude UUIDs and OpenCode `ses_` ids) while still rejecting traversal ids, keeping shell and Python validation in agreement. The README install section documents the OpenCode setup.
